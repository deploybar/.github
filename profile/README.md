# deploybar

**Your deployments. One click away.**

deploybar brings deployment status, logs, and deployment actions to the Windows system tray and macOS menu bar.

We're building a desktop companion for checking how a deployment is going, reading its logs, and triggering the next one without digging through provider dashboards.

The project focuses on deployment services such as Laravel Forge, Ploi, and Vercel, bringing those workflows closer to where you work.
